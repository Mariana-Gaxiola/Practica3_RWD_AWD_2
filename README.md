Hadware.P instalacion AWD

---Requisitos:

Debes tener instalado:

*Node.js (Versión 16 o superior recomendada).

---Instalacion y configuracion:

1- Clona este repositorio o descarga los archivos en la carpeta que desees trabajar 

2- Abre una terminal

3- Instala las dependencias que vamos a necesitar ejecutando el siguiente comando en la tarminal:

 npm install express express-useragent ejs


---Estructura del Proyecto

Debes asegurarte de que las carpetas queden en este orden, de lo contrario puedes llegar a necesitar modificar las rutas:

Practica 3/
├── Img/                  # Carpeta de imagenes
├── node_modules/         # Dependencias de Node
├── views/
│   ├── desktop.ejs       # Vista para compu
│   └── mobile.ejs        # Vista para movil
├── server.js             # Servidor principal 
└── package.json


---Arranque del Servidor

Para iniciar el servidor, ejecuta el siguiente comando en la terminal:

node server.js


Una vez iniciado, abre tu navegador web e ingresa la url que te lanza el comando
